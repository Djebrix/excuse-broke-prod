One line, at most 180 characters, that an AI agent says to its human right
after breaking production. An excuse, from the machine's own mouth — and
funny.

`main.py` (stdlib only, no network, deterministic) writes the line to
`entry.txt` inside `$ENTRY_OUTPUT_DIR` (default `/output`), asserting the
1–180 character range.

Run it:

```sh
python3 main.py
```
